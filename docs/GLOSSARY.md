# Glossary

Domain terms used in code, docs, and UI. Add an entry the first time a term lands in the codebase.

| Term                        | Definition                                                                                                                                                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Grid**                    | The N×N board of `NumberTile`s. N depends on the active config (3 for Easy, 4 for Medium, 5 for Hard / large-grid puzzles).                                                                                                   |
| **Tile**                    | One cell of the grid containing a number 1–9.                                                                                                                                                                                 |
| **Operator**                | One of `+`, `-`, `*`. Rendered between adjacent tiles. Division (`/`) was removed in EPIC-06 — see ADR-002.                                                                                                                   |
| **Path**                    | An ordered sequence of adjacent tiles selected by the player, alternating tile → operator → tile … . Must be straight (all in one row, or all in one column) and contiguous (no skipped tiles).                               |
| **Target**                  | The number the player must produce by combining their selected tiles with their selected operators, evaluated **left-to-right with no operator precedence**.                                                                  |
| **Round**                   | One target. The player has one selected path attempt before the round resolves. Classic mode = 5 rounds; Learn levels and Daily Puzzle = 1 round.                                                                             |
| **Combination**             | A `(tiles, operators, result)` triple representing a valid path on the current grid. Generated by `getAllCombinations` and used to derive targets and `optimalSolution`s.                                                     |
| **Solution**                | A path whose evaluation equals the round's target.                                                                                                                                                                            |
| **Optimal Solution**        | A `Solution` recorded on a static `Puzzle` at generation time and validated by `npm run puzzles:validate`. Currently any one valid solution per puzzle; future work may pick the shortest / lowest-rating path.               |
| **Hint**                    | Highlights one valid solution for the current target. Auto-clears after 5s.                                                                                                                                                   |
| **Difficulty**              | `easy` / `medium` / `hard`. Controls grid size, tile count per path, available operators, and target range. Also a `Puzzle.difficulty` field on each puzzle in `puzzles.json`.                                                |
| **Game Mode**               | Top-level game variant: `classic`, `timeAttack`, `quickGame`, `learning` (Learn path), `dailyPuzzle` (`/daily`). `endless` and `puzzle` are typed but not implemented.                                                        |
| **Quick Game**              | One-tap entry from the Play lobby. Uses the easy config (3×3, 2 tiles + 1 operator). Per ADR-002, the operator-count picker was removed.                                                                                      |
| **Time Attack**             | Solve as many rounds as possible in 60 seconds. Score doubled.                                                                                                                                                                |
| **Classic**                 | Fixed-round play (default 5).                                                                                                                                                                                                 |
| **Learn**                   | Tabbed home (default tab) showing 25 hand-authored levels in 5 units, gated by progress. See ADR-003 and `progressStore.levels`.                                                                                              |
| **Score**                   | `baseScore (10) × difficultyMultiplier × modeMultiplier`. Difficulty: easy 1, medium 1.5, hard 2. Time Attack ×2.                                                                                                             |
| **Round time / Total time** | `gameStore.roundTime` is wall-clock since the current round started; `gameStore.totalTime` is the sum across all completed rounds plus the current round's elapsed (via the `roundsTimeMs` accumulator). Fixed in EPIC-05.05. |
| **Stars**                   | Accuracy-based rating awarded when a Learn level finishes: 3 = no wrong taps, 2 = ≤1 wrong tap, 1 = completed. `bestStars` per level is best-of and never decreases. Pure helper `computeStars(wrongAttempts)`.               |
| **XP**                      | Long-running counter on `progressStore.xp`. Earned only on _star improvements_ (`(newStars − oldStars) × 10`), so repeating a level doesn't farm XP. Shown in the home header.                                                |
| **Streak (Learn)**          | `progressStore.streak` — consecutive UTC days with at least one Learn-level completion. Gap > 1 day resets to 1. No freezes, no notifications.                                                                                |
| **Daily Streak**            | `progressStore.dailyStreak` — consecutive UTC days with a Daily Puzzle completion. **Independent** from the Learn streak, so missing one doesn't punish the other. Same gap-reset rule.                                       |
| **Audience / Kids mode**    | `prefsStore.audience: 'adult' \| 'kids'`. Kids mode hides the score / round / difficulty strip in `ButtonGameBoard` and replaces stars + XP with a "🎉 Great job!" cue on the Learn result page. Progress is still recorded.  |
| **Zen mode**                | `prefsStore.zen` — toggles via the floating 🧘 button or the `Z` key. Hides the game-board chrome (header, score row); the grid, target, hint, and clear remain.                                                              |
| **Theme (UI)**              | `prefsStore.theme: 'light' \| 'dark' \| 'system'`. Applied via `<html class="dark">` by `ThemeApplier`.                                                                                                                       |

## Phase 2+ terms (Puzzles)

| Term                | Definition                                                                                                                                                                                                                                                        |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Puzzle**          | A persisted, identifiable round: a concrete grid (tile values fixed at generation time), a target, one or more themes, a difficulty bucket, an `optimalSolution`, and a numeric rating. Defined in `Puzzle` (`src/types/game.ts`). Distinct from a Classic round. |
| **Puzzle Bundle**   | The shape of `public/puzzles.json` — a versioned envelope (`schemaVersion`, `generatedAt`, `count`, `puzzles`) shipped as a static asset. `PuzzleBundle` in `src/types/game.ts`.                                                                                  |
| **Theme**           | A tag describing what kind of arithmetic a puzzle exercises. Currently shipped: `addition-only`, `subtraction-only`, `mixed-add-sub`, `multiplication`, `mixed-all`, `large-grid`. Future: `parity`, `primes-only-targets`. (Division was removed — see ADR-002.) |
| **Rating (puzzle)** | Numeric difficulty in `[800, 2200]`, computed at generation time by `computeRating(config, solution, target)`. Glicko-style scale; not yet a real Glicko-2 number (that's Phase 3 / EPIC-29).                                                                     |
| **Seeded RNG**      | `xmur3 + mulberry32` in `src/utils/rng.ts`. Any string seed → reproducible stream. Backbone of the puzzle generator and the Daily Puzzle picker.                                                                                                                  |
| **Daily Puzzle**    | One puzzle per UTC day, identical for everyone. Picked deterministically by `pickDailyPuzzle(puzzles, date)` from the shipped bundle. Lives at `/daily`. Banner on the Learn home (`DailyPuzzleBanner`) shows today's status + streak.                            |
| **Streak (Daily)**  | See "Daily Streak" above. _(The vague "consecutive correct puzzle solves; one wrong answer resets to 0" definition belongs to **Puzzle Streak / EPIC-53**, not the Daily Puzzle streak — those are different mechanics.)_                                         |
| **Storm**           | 3-minute time-pressured puzzle rush. Skipping costs time; harder puzzles award more points. EPIC-24.                                                                                                                                                              |
| **Puzzle Streak**   | Endless chain of solves; first wrong answer ends the run; difficulty scales with the streak. EPIC-53 (renumbered from a colliding EPIC-25).                                                                                                                       |
| **Practice**        | Free-form puzzle solving filtered by theme + difficulty rating; doesn't break a streak. Picker UI is EPIC-21.02 (not yet shipped).                                                                                                                                |

## Phase 3+ terms (Accounts & ratings)

| Term               | Definition                                                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Account / User** | A signed-in identity with handle, ratings, history.                                                                                   |
| **Guest**          | An unsigned visitor with local-only progress. Can upgrade to Account, carrying progress.                                              |
| **Profile**        | Public page at `/u/<handle>` showing ratings, recent activity, shields.                                                               |
| **Glicko-2**       | The rating system. Stores `(rating, deviation, volatility)` per user per mode. Updated in periods.                                    |
| **Rating period**  | A fixed wall-clock window (e.g. 7 days) over which Glicko-2 batches results before updating.                                          |
| **Kids account**   | A COPPA-aware account variant: no public profile, no chat, no leaderboard exposure beyond opt-in. Requires parent email verification. |

## Phase 4+ terms (Multiplayer)

| Term                     | Definition                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| **Match / Game session** | A single multiplayer instance between two players, with a shared sequence of rounds.        |
| **Lobby**                | The matchmaking surface. Players enter, are paired by rating, get sent into a Match.        |
| **Bracket**              | A rating window used by matchmaking (e.g. ±200 Glicko); widens over time if no match found. |
| **Spectator**            | Read-only viewer of a live Match.                                                           |
| **GG TV**                | Auto-rotating channel of high-profile live matches, akin to Lichess TV.                     |
| **Rematch**              | One-click re-pair of the same two players for another Match.                                |
| **Berserk**              | Optional pre-match modifier: halve your time, double your potential points.                 |

## Phase 5+ terms (Tournaments)

| Term            | Definition                                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Arena**       | A timed tournament window during which players play continuous back-to-back matches; ranked by points + streak bonus. |
| **Swiss**       | A tournament with a fixed number of rounds where players are paired each round by current score, no rematches.        |
| **Shield**      | A persistent badge awarded to winners of a recurring monthly themed tournament.                                       |
| **Team / Club** | A group of users (school class, friend group). Can have a private leaderboard and team-vs-team tournaments.           |
